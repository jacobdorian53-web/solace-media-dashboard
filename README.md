# Solace Media Dashboard — Jay

Live shared dashboard for Jay (media buyer), Jacob, and Billy. This is the single source of truth for Jay's weekly schedule, tasks, and questions.

## How this works
- **`CURRENT_WEEK.md`** — the active week. This is what Jay works off day to day. Check the boxes as you go.
- **`weeks/`** — archive of past weeks. At the start of each new week, the finished `CURRENT_WEEK.md` gets copied into `weeks/` with its date, and a fresh one is started from `TEMPLATE.md`.
- **`TEMPLATE.md`** — the blank weekly template. Don't edit this except to improve the recurring structure.
- **`REFERENCE.md`** — standing info: accounts, key links, targets, how we run things. Read once, refer back as needed.

## The rhythm
- **Daily:** check performance, make sure everything's spending, flag issues.
- **Weekly sync (Jacob + Jay):** go through the Questions section together, review what got done, set the next week.

## Editing
Everyone can edit directly on GitHub (pencil icon on any file) or in the app. Billy can read/write programmatically to keep things updated.
